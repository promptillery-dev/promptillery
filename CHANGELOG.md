# Changelog

## 0.2.0 — 2026-09-24 (EACL 2027 demo submission)
- Recommender: the teacher is a candidate below the break-even volume; student-training GPU time is priced into the distillation intercept; `recommend` reads `training_seconds`.
- Recommender evaluation on the frozen Banking77 cells (`examples/demo/`), price sensitivity (`scripts/recommender_sensitivity.py`).
- Corrected baselines: encoder baselines re-run with `warmup_steps: 10` (`examples/paper/M6_*`), and the RoBERTa and Ettin-encoder promptillery loops re-run with warm-up 10 (`examples/paper/G3_*_ettin_encoder_w10.yaml`, run records under `out/g3/`).
- Compute-matched controls: same-N fine-tuning with matched training compute at warm-up 500 and warm-up 10 (`same_n_cm`, `same_n_cm_w10`; configs from `scripts/gen_m6_configs.py`, results in `docs/M6_RESULTS.md`).
- Batch-8 latency profiles for the retrained Banking77 students (`out/g2/*/profile-bs8.json`); recorded only, the recommender inputs are unchanged.
- Table provenance index (`docs/TABLE_PROVENANCE.md`, generated by `scripts/table_provenance.py`) maps every reported number to its run record.
- Demo replay: `promptillery recommend` and `promptillery paper-figures` on the frozen Banking77 artifacts reproduce the recommendation without a GPU; CI runs it after the tests.
- M5 same-N configs ship for provenance (superseded for Table 2).
- Engine records `training_seconds` in `run_manifest.json`.
- Prices and targets fixed by stated rules with dated sources.
- Evaluation batch size (`eval_batch_size`, default 64) is independent of the training batch size; predictions are unchanged, held-out passes on large test splits run several times faster.
